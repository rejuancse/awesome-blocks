Awesome Blocks is a collection of 10 beautiful and customizable Gutenberg blocks for WordPress. Create stunning layouts with ease using our feature-rich blocks including sliders, timelines, galleries, and WooCommerce integrations.

== Description ==

Awesome Blocks is a powerful WordPress plugin that extends the Gutenberg editor with 10 custom, beautifully designed blocks. Whether you're building a portfolio, e-commerce site, blog, or business website, Awesome Blocks provides the tools you need to create engaging and professional content without any coding knowledge.

## Available Blocks

### 1. Awesome Slider
A beautiful slider block with smooth animations and Slick Slider integration. Features include:
- Autoplay with customizable speed
- Navigation arrows and dot indicators
- Multiple slide support with images, titles, and buttons
- Content positioning options
- Animation speed controls

### 2. Awesome Timeline
Create stunning vertical timelines with alternating left/right items. Perfect for:
- Company history and milestones
- Project roadmaps
- Event schedules
- Storytelling and journey showcases

### 3. Card Block
Beautiful card layouts with comprehensive content display:
- Image support with customizable alignment
- Tag, date, and author information
- Excerpt and button controls
- Multiple display options
- Perfect for blog posts and featured content

### 4. Feature Block
Display features or services with style:
- Customizable icons (Dashicons support)
- Icon color and background controls
- Title and description fields
- Optional link support
- Flexible alignment options

### 5. Hero Video
Create impactful hero sections with video backgrounds:
- Video autoplay and loop options
- Overlay color and opacity controls
- Customizable typography (title, description, button)
- Content alignment and padding options
- Muted playback support

### 6. Image Compare
Interactive before/after image comparison:
- Drag slider to compare images
- Perfect for showcasing transformations
- Great for portfolios, retouching services, and more
- Touch-friendly on mobile devices

### 7. Photo Gallery
Beautiful responsive photo gallery with:
- Lightbox popup functionality
- Customizable columns and gutter spacing
- Multiple hover effects (zoom, fade, etc.)
- Caption support
- Image aspect ratio controls
- Navigation controls

### 8. Post Block
Display posts with customizable layouts:
- Grid layout with column control
- Show/hide title, excerpt, date, author, and thumbnail
- Customizable typography for all elements
- Category filtering
- Color customization options
- Card styling controls

### 9. WooCommerce Category Grid
Display WooCommerce product categories beautifully:
- Grid layout with customizable columns
- Show/hide category images and product counts
- Order and orderby controls
- Hide empty categories option
- Image size selection

### 10. WooCommerce Product List
Showcase WooCommerce products in style:
- Grid layout with column control
- Category filtering
- Display options: price, rating, add to cart, badges
- Badge position controls
- Sorting options
- Perfect for shop pages and product showcases

== Installation ==

= Minimum Requirements =

* PHP version 7.4 or greater
* WordPress 5.9 or greater

= Automatic Installation =

1. Log in to your WordPress dashboard
2. Navigate to "Plugins" > "Add New"
3. Search for "Awesome Blocks"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the awesome-blocks.zip file
2. Go to Dashboard > Plugins > Add New
3. Click "Upload Plugin"
4. Select the awesome-blocks.zip file and click "Install Now"
5. Activate the plugin

== Frequently Asked Questions ==

= Q. How do I use the blocks? =
A. After activating the plugin, go to any page or post and click the "+" (add block) button. Search for "Awesome" to see all available blocks from the plugin.

= Q. Are these blocks responsive? =
A. Yes, all blocks are fully responsive and work perfectly on desktop, tablet, and mobile devices.

= Q. Do I need coding knowledge? =
A. No coding knowledge is required. All blocks can be customized through the block settings in the Gutenberg editor.

= Q. Do these blocks work with any theme? =
A. Yes, Awesome Blocks is designed to work with any WordPress theme that supports the Gutenberg editor.

= Q. Where can I get support? =
A. You can get support by posting on the support forum on WordPress.org or via email at: hello@thebitcraft.com

= Q. Can I use these blocks with WooCommerce? =
A. Yes! We have dedicated blocks for WooCommerce - Category Grid and Product List blocks that integrate seamlessly.

= Q. Where can I report a bug or request a feature? =
A. Please use the support forum on WordPress.org or email us at: hello@thebitcraft.com
